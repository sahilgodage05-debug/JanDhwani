## 🏛️ About JanDhwani

**JanDhwani** (*Voice of the People*) is a next-generation civic technology platform that empowers citizens across all linguistic backgrounds in India and BRICS partner nations to report civic and infrastructure issues using natural voice, live camera feeds, and automated GPS geolocation.

It provides a hierarchical **3D Digital Twin Governance Simulator** for Central Ministries, State Secretariats, District Magistrates (DMs), and Hyper-Local Wards to monitor live problem beacons, dispatch emergency budgets, and remediate civic deficits in real time.

---

## 🌟 Core Architecture & Features

### 1. 🎙️ Multilingual Voice AI Engine
* **22 Indian Scheduled Languages + BRICS (Portuguese):** Real-time speech recognition and text synthesis across Hindi, Marathi, Tamil, Telugu, Bengali, Kannada, Gujarati, English, and more.
* **Dialect & Accent Resilient:** Powered by automated phonetic normalizers and Google Gemini 1.5 Flash structured decomposition.
* **1-Click Voice Evaluation Studio:** Preset multi-state test scripts for instant evaluation.

### 2. 📸 Multimodal Image Evidence & Live Hardware Lens
* **Live Camera Snapshot Simulator:** Capture on-ground visual evidence directly in-browser.
* **Gemini Vision AI Audit:** Automatic defect classification and confidence verification.

### 3. 🌐 3D Digital Twin Spatial Governance (Three.js WebGL)
* **Hierarchical Zoom Tiers:**
  * `National / Central Ministry` — Pan-India telemetry and macro budget prioritization.
  * `State Level` — State-level ministry routing.
  * `District Magistrate (DM)` — District administration dispatch.
  * `Hyper-Local Ward / Village` — Sub-meter GPS fix (±2m accuracy) and ground radar telemetry.
* **Interactive 3D Beacons:** Dynamic color-coded pillars pulsing with real-time urgency weights.
* **Integrated Satellite Verification:** Embedded Google Maps geospatial feeds.

### 4. 🏁 Dual-Role Resolution & Archival Protocol
* **Citizen Sign-Off:** Citizen star satisfaction rating + ground verification note.
* **Government Authority Sign-Off:** Remediation summary, designated signing engineer, and budget tracking.
* **Auditable Resolved Ledger:** Concise records archive with unique audit IDs (`#AUD-XXXXXX-VERIFIED`), search/filter by ministry, and JSON export.

### 5. 🛡️ Official Digital India Aesthetic & DPI Standards
* **Official State Emblem of India (Lion Capital of Ashoka & सत्यमेव जयते).**
* **DigiLocker & OTP Citizen Authentication.**
* **Offline-Ready Local Storage Sync.**

## 🍴 How to Fork and Contribute

Follow these step-by-step instructions to fork this repository, run it locally, and contribute your improvements.

### Step 1: Fork the Repository on GitHub
1. Navigate to the main repository: [https://github.com/AditiGhule31/JanDhwani](https://github.com/AditiGhule31/JanDhwani)
2. In the top-right corner of the page, click the **`Fork`** button.
3. Choose your personal GitHub account as the owner and click **`Create Fork`**.

### Step 2: Clone Your Fork Locally
Open your terminal or command prompt and run:
```bash
git clone https://github.com/<YOUR_GITHUB_USERNAME>/JanDhwani.git
cd JanDhwani/frontend
```

### Step 3: Configure Upstream Remote
Keep your fork synchronized with the original repository by adding the upstream remote:
```bash
git remote add upstream https://github.com/AditiGhule31/JanDhwani.git
git remote -v
```

### Step 4: Install Dependencies
Ensure you have **Node.js (v18+)** installed, then run:
```bash
npm install
```

### Step 5: Run the Development Server
Start the local Vite development server:
```bash
npm run dev
```
Open your browser and navigate to:
```
http://localhost:5173/
```

### Step 6: Create a Feature Branch
Before making changes, create and switch to a new branch:
```bash
git checkout -b feature/your-feature-name
```

### Step 7: Commit and Push Your Changes
```bash
git add .
git commit -m "feat: description of your improvement"
git push origin feature/your-feature-name
```

### Step 8: Open a Pull Request (PR)
1. Go to your forked repository on GitHub.
2. Click **`Compare & pull request`**.
3. Fill in the title and description explaining your changes.
4. Click **`Create pull request`**.
